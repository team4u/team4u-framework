# Team4u Config

Team4u Config 是一个轻量级、模块化、强类型安全的 Java 配置管理框架。

## 模块说明

| 模块                     | 说明                     | 文档                                          |
|:-----------------------|:-----------------------|:--------------------------------------------|
| **team4u-config-core** | 核心引擎：支持代理模式、多源聚合、热重载。  | [README.md](./team4u-config-core/README.md) |
| **team4u-config-db**   | 数据库插件：支持从关系型数据库动态加载配置。 | [README.md](./team4u-config-db/README.md)   |
