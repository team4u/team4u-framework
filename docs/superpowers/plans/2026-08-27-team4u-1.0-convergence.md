# Team4u Framework 1.0 Convergence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`. Dispatch one fresh implementation subagent per task. A separate review subagent must review every task before commit. Do not implement tasks inline unless the user explicitly stops the subagent workflow.

**Goal:** Ship the approved breaking Team4u 1.0 convergence with explicit provider/adapter boundaries, runnable first-use paths, enforceable dependency graphs, and evidence-backed release claims.

**Architecture:** The root POM becomes the only parent, aggregator, and complete BOM. Core modules lose optional runtime couplings; proxy, Spring, Jackson, Config, and governance choices move to explicit downstream artifacts. Each task is independently testable, reviewed, committed, and revertable.

**Tech Stack:** Java 8 bytecode, Maven 3.9.x, JUnit 4, Maven Enforcer Plugin, Maven Invoker Plugin, Spring 5.3 plain `@Configuration`, optional ByteBuddy, Jackson provider-only, and JMH for advertised performance paths.
